How do I get an access key?
The access key is created once by the site owner and shared with editors like a password:
1. On GitHub: Settings → Developer settings → Fine-grained tokens → Generate new token.
2. Repository access: Only select repositories → eli-links.
3. Permissions: Contents → Read and write. Nothing else.
4. Copy the key (starts with github_pat_) and keep it safe.
